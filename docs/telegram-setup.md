# 텔레그램 관리자 예약 알림 연결

신규 예약 신청, 예약 변경 요청, 예약 취소 요청이 저장되면 지정한 텔레그램 개인 대화로 알림을 보냅니다.
알림은 요청 종류와 관리자 페이지 링크만 포함합니다. 성함·전화번호·생년월일·건강 정보·예약 일시는 보내지 않습니다.
예약 확정과 변경·취소 승인은 기존처럼 관리자 페이지에서 진행합니다.

## 1. 휴대폰 준비

1. 텔레그램 앱을 설치하고 본인의 계정으로 로그인합니다.
2. 휴대폰 설정에서 텔레그램 알림을 허용합니다.
3. 아래에서 만들 봇의 대화방도 알림을 켜 둡니다.

## 2. 알림용 봇 만들기

1. 텔레그램의 공식 [BotFather](https://t.me/BotFather)를 엽니다. 계정 이름이 정확히 `@BotFather`인지 확인합니다.
2. **시작**을 누르고 `/newbot`을 보냅니다.
3. 표시 이름을 물으면 `분당튼튼운동센터 예약 알림`을 보냅니다.
4. 사용자 이름을 물으면 영문·숫자·밑줄로 된 이름을 입력합니다. 전체 길이는 5~32자이고 끝은 `bot`이어야 합니다.
   예: `bundang_teunteun_booking_bot`. 이미 사용 중이면 숫자를 붙여 다른 이름으로 만듭니다.
5. BotFather가 보내 준 **HTTP API token**을 복사합니다. 숫자와 `:`로 시작하는 긴 값입니다.
   이 값은 다음 단계의 터미널 입력란에만 붙여 넣습니다. 채팅, 소스 코드, 공개 문서에 적지 않습니다.

## 3. VS Code에서 연결하기

기존 `.booking-local.json`이 있는 홈페이지 프로젝트를 열고 진행합니다. Firebase 설정을 다시 만들 필요는 없습니다.

1. VS Code 상단 **터미널 → 새 터미널**을 누릅니다.
2. 다음 명령을 실행합니다.

   ```sh
   npm run telegram:setup
   ```

3. `봇 토큰:`이 나오면 복사한 토큰을 붙여 넣고 Enter를 누릅니다.
   **입력 내용이 화면에 표시되지 않는 것이 정상입니다.**
4. 터미널에 나온 `https://t.me/…` 링크를 휴대폰 텔레그램에서 엽니다.
5. 방금 만든 봇의 개인 대화방에서 **시작**을 누릅니다. BotFather 대화방이 아닙니다.
6. 터미널이 표시한 `센터예약연결-…` 문구를 그대로 봇에 보냅니다.
7. VS Code 터미널로 돌아와 Enter를 누릅니다.
8. 표시된 수신 계정 이름이 본인인지 확인하고 `y`를 입력한 뒤 Enter를 누릅니다.
9. 휴대폰에 **예약 알림 연결 테스트가 완료되었습니다**라는 메시지가 오는지 확인합니다.

연결에 성공하면 `.booking-local.json`에 아래 두 항목이 자동으로 추가됩니다.

| 로컬 설정 항목 | 의미 |
| --- | --- |
| `telegramBotToken` | 봇의 비밀 토큰 |
| `telegramChatId` | 알림을 받을 개인 대화 ID |

이 파일은 Git 제외 대상이며, 빌드 결과에도 들어가지 않습니다. 두 값은 브라우저에 제공되지 않습니다.
설정 도구는 실행할 때만 동작하므로 계속 켜 둘 필요가 없습니다. 봇을 다른 자동화에 함께 연결하지 말고 예약 알림 전용으로 사용하세요.

## 4. 로컬에서 세 가지 알림 확인하기

1. 기존 로컬 서버가 실행 중이면 해당 터미널에서 Ctrl+C로 종료합니다.
2. 다음 명령으로 다시 실행합니다.

   ```sh
   npm run dev:local
   ```

3. 컴퓨터에서 <http://localhost:8790/reservation.html>을 엽니다.
4. 본인 전화번호와 테스트용 내용으로 **미래 날짜**의 예약을 신청합니다.
5. 텔레그램에 `[로컬 테스트]`와 함께 **새 예약 신청** 알림이 오는지 확인합니다.
6. **내 예약 조회·변경**에서 전화번호로 조회하고 다른 미래 일시로 변경을 요청합니다.
7. **예약 변경 요청** 알림이 오는지 확인합니다.
8. 컴퓨터에서 <http://localhost:8790/admin.html>에 로그인하고 변경 요청을 승인하거나 거절합니다.
   이미 처리 대기 중인 요청이 있으면 추가 취소 요청이 차단되므로 먼저 처리해야 합니다.
9. 고객 조회 화면에서 다시 조회한 다음 취소를 요청합니다. **당일 예약은 취소 요청을 할 수 없습니다.**
10. **예약 취소 요청** 알림이 오는지 확인하고 관리자 페이지에서 취소를 승인합니다.
11. 종료된 테스트 예약은 관리자 페이지에서 삭제할 수 있습니다.

현재 로컬 서버도 실제 연결된 Firestore에 기록합니다. 테스트에는 본인 번호를 사용하세요.
`localhost`는 해당 컴퓨터 주소이므로 로컬 알림의 관리자 주소는 휴대폰에서 열리지 않습니다.
운영 사이트에서 보낸 알림에는 휴대폰에서도 열 수 있는 **관리자 페이지 열기** 버튼이 붙습니다.

## 5. 운영 사이트 연결하기 — 배포할 때 진행

로컬 설정만으로 운영 사이트에 알림이 켜지지는 않습니다. 지금은 커밋·배포하지 않아도 로컬 테스트가 가능합니다.

1. Cloudflare 대시보드에서 **Workers & Pages → bundang-teunteun-sports-medicine-center** 프로젝트를 엽니다.
2. **Settings → Variables and Secrets**에서 **Production** 환경을 선택합니다.
   화면 버전에 따라 `Environment variables`로 표시될 수 있습니다.
3. 아래 두 값을 각각 **Secret(암호화)** 유형으로 추가하고 저장합니다.

   | Cloudflare 이름 | 넣을 값 |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | `.booking-local.json`의 `telegramBotToken` 값 |
   | `TELEGRAM_CHAT_ID` | `.booking-local.json`의 `telegramChatId` 값 |

   JSON의 따옴표와 쉼표는 빼고 값만 복사합니다. 기존 Firebase·Turnstile 설정은 그대로 둡니다.
4. `SITE_ORIGIN`이 `https://bundang-teunteun-sports-medicine-center.pages.dev`인지 확인합니다.
   이 주소로 관리자 링크를 만듭니다.
5. 정식 반영을 결정했을 때 **이번 코드가 포함된 버전을 배포**합니다.
   환경변수만 저장하거나 이전 코드를 재배포하면 새 알림 기능이 추가되지 않습니다.
6. 운영 사이트에서 본인 번호로 신청 → 변경 요청 → 취소 요청을 확인합니다.
7. 알림의 **관리자 페이지 열기**를 눌러 로그인한 후 요청을 처리합니다.

`npm run dev`로 Wrangler를 사용하는 경우에는 `.dev.vars`에 같은 이름의 두 값을 넣습니다.
`npm run dev:local`은 `.booking-local.json`을 읽으며, `.dev.vars`를 읽지 않습니다.

## 알림이 오지 않을 때

- 아무 값도 설정하지 않으면 텔레그램 알림만 꺼지고 예약 기능은 유지됩니다.
- 봇 대화방의 알림 음소거, 휴대폰 알림 권한, 봇 차단 여부를 확인합니다.
- 로컬에서는 설정 후 서버를 재시작했는지, 운영에서는 두 Secret과 새 코드가 포함된 배포가 완료됐는지 확인합니다.
- 봇 토큰이 변경됐다면 설정 도구를 다시 실행하고 Cloudflare의 토큰도 갱신합니다.
- 일시적인 네트워크·텔레그램 서버 오류는 한 번 재시도합니다. 영구 오류는 반복 전송하지 않습니다.
- 최종 실패는 서버 로그에 `telegram_notification_failed`와 오류 코드로 기록합니다. `401`은 토큰, `403`은 봇 차단이나 대화 접근, `400`은 대화 ID 등을 확인합니다.
  로그에는 토큰·대화 ID·예약자 정보가 기록되지 않습니다.
- 알림 전송에 실패해도 접수된 예약은 유지됩니다. 장기 장애 이후 자동 재발송하는 대기열은 없으므로 관리자 페이지도 정기적으로 확인합니다.
- 전송은 됐지만 응답이 끊긴 경우, 한 번의 재시도로 같은 알림이 두 번 도착할 수 있습니다. 예약이 두 번 생성됐다는 뜻은 아닙니다.
- 예약 조회, 관리자 승인·확정, 실패한 신청에는 알림을 보내지 않습니다. 이미 접수된 신규 신청의 재전송에도 새 알림을 보내지 않습니다.

공식 참고: [Telegram 봇 생성](https://core.telegram.org/bots/tutorial), [Bot API](https://core.telegram.org/bots/api).
